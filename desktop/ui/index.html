1 · 检查与初始化

PLA 自动创建独立用户配置、日志、缓存和运行数据目录。既有开发者安装不会被自动接管。

Runtime 与 Tunnel 使用独立端口；如果端口被占用，请停止服务后修改。

2 · 配置自己的 Tunnel

使用官方页面创建 Tunnel 和此电脑专用的 runtime API key。账户、组织权限及 ChatGPT 授权需由你完成。保存配置前请停止服务。

凭据由当前 Windows 用户的 DPAPI 加密保存，界面不会读取已保存的密钥。

3 · 授权工作区并验证本地调用

在「授权工作区」添加允许访问的目录并明确读、写、执行权限。然后启动 Runtime，运行本地诊断工具，再连接 Tunnel。

4 · 在 ChatGPT 侧完成连接

按照官方连接文档，在 ChatGPT 添加此 Tunnel 对应的应用或 MCP 连接，完成授权。请先让 ChatGPT 列出授权目录，再创建和修改一个测试文件，最后执行受控进程。

本地验证成功不会标记为 ChatGPT 验收通过。请在验收手册中记录真实调用结果。

已授权目录

支持多个 root，每个名称对应一个独立目录。变更授权前需要停止 Runtime。移除授权会保留目录中的文件。

添加新的 root

添加第二个目录时，请使用新的 root 名称。修改已有目录请点击列表中的「编辑」，新增不会覆盖已有授权。

尚未加载日志

PLA Desktop V1

本地未签名测试发行候选。自动更新已禁用，安装新版本前应验证下载来源和 SHA-256 校验值。配置存储在独立用户目录，升级及卸载保留用户数据。

关闭主窗口后保留在托盘。托盘提供打开、状态、启动、停止与彻底退出。彻底退出会释放本应用拥有的进程。

浏览器执行组件

安装包包含固定版本的 Node 与 Playwright MCP，浏览器使用系统 Microsoft Edge。请停止服务后保存偏好，再启动 Runtime。启用后可通过 ChatGPT 调用原有浏览器能力。

Office 和 Skills 依赖独立外部组件。当前候选未包含这些组件，状态显示不可用；请查看发行说明中的限制。
