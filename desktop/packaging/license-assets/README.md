# Reviewed supplemental license texts

These public texts fill omissions in otherwise pinned distribution archives. `manifest.json` binds the exact package/version, upstream source URL and SHA-256. The build copies only a matching entry and rejects changed bytes or escaping paths; it does not retrieve new licenses at build time.

Dnspython 2.9.0 and FastMCP slim 4.0.3 lack notice files in their installed wheels. Their project release texts are preserved here. Alloc-stdlib 0.3.0 and the WebView2 crates use the corresponding upstream commit from Cargo's packaged VCS metadata. Selectors 0.38.0 declares MPL-2.0 in its Cargo metadata and source headers but omits a full license text; the SPDX MPL-2.0 text is retained with a fixed local hash and its upstream URI.

The tauri-plugin 2.7.2 crate omits a bundled license text; its Cargo package declares `Apache-2.0 OR MIT`. The reviewed supplement preserves the official upstream MIT-license option from the `tauri-plugin-v2.7.2` tag, with its exact bytes pinned by SHA-256.\n\nThe actual target's MPL source archives are copied separately from Cargo's cache and must match Cargo.lock checksums. When `cargo fetch` has downloaded a required crate but `registry/src` has not been populated, the packager now preserves the checksum-verified `.crate` source archive, reads contained license texts and Cargo metadata, and still requires a preserved license text (from the crate or a reviewed supplement). Other dependency texts come from their actual installed distribution/registry files. This supplements the license inventory; it does not assert public-release approval or grant a license for the first-party PLA repository.
