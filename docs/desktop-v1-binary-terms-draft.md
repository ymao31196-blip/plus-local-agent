## 拟定许可框架

1. 用户通过官方公开渠道合法获取PLA Desktop安装包后，权利人授予用户
   一项非独占、不可转让的许可，允许在自己的Windows设备上安装并
   运行PLA Desktop二进制程序。是否允许商业用途、多设备使用，
   应由发行负责人另行确定；本草案暂不施加推定限制。
2. 除依法允许或者第三方许可证明确授予的权利外，本许可不授予PLA自有
   源码的复制、修改、重新分发或衍生作品制作许可，也不授予以PLA名义
   再发行修改版本或冒充官方发行的权利。
3. 软件随包的第三方程序、库及相关告知文本仍适用各自许可条款；
   若第三方许可允许用户行使比本条款更宽的权利，则本条款不限制该权利。
4. PLA可执行受用户授权的本地工具。用户应谨慎设置工作区和可执行程序授权；
   程序以当前Windows账户权限运行，可能影响工作区以外的资源。
5. 安装包当前未签名，采用手动升级方式，不承诺自动回滚、持续联网可用，
   或在所有Windows环境与第三方MCP组件下均能正常工作。
6. 应根据适用法律确定合理的保证、责任限制、终止及争议处理条款，
   不得排除法律不允许排除的消费者权利。
