# PLA v1.0.0 二进制发行与源码权利保留方案

状态：**发行方案已确定，仓库迁移尚未执行**（2026-10-24）。
本文件记录发布决策，不是已生效的许可协议，也不是发布完成证明。

## 发行决策

PLA v1.0.0面向Windows 10/11 x64用户公开提供可安装的二进制发行包。
PLA自有源码暂不选择MIT、Apache-2.0、GPL等通用开源许可，原创部分的复制、
修改和再分发权利由相应权利人保留。用户获得的软件使用权应通过单独的二进制使用条款明确。
对第三方依赖和组件，仍须遵守各自许可；“PLA保留权利”不覆盖第三方作品。

**当前真实状态**：`ymao31196-blip/plus-local-agent`仍为**Public**源码仓库。
GitHub的公开仓库即使没有LICENSE，也可被查看、Fork；公开Release会自动
附带该Tag所在仓库的源码zip和tar.gz。因此，不能在当前公开源码仓库下
发布“只公开安装包、未来源码不公开”的v1.0.0。

## 建议的双仓库布局

1. **Private开发仓库**：保留现有源码、Git历史、开发测试、CI、构建输入和内部
   release审计。优先保留当前仓库`ymao31196-blip/plus-local-agent`作为该仓库，
   但不能在公开下载迁移之前将其设为Private。
2. **Public下载仓库**：单独创建只放公开说明、安装指南、更新日志、校验文件和
   GitHub Releases资源的轻量仓库（暂用拟名`plus-local-agent-downloads`，
   **尚未创建**）。公开Tag只引用此仓库中的下载说明；自动生成的Source code
   zip/tar.gz不会含PLA Runtime的开发源码。
3. **分发路线**：私有源码 → 本地/私有CI构建并验证 → 安装包、SHA256SUMS、
   精简可公开的build-manifest、第三方告知文本 → Public下载仓库Release。
   不公开源仓库CI日志、含凭据的构建缓存、私有Git URL或含敏感环境路径的清单。
   安装包可被分析和逆向；私有源码不等于二进制不可逆向。

## 安全迁移顺序（须按序验收）

1. **许可与权属**：由发行负责人最终确认PLA自有代码权属和二进制使用条款；
   核实全部随包第三方依赖的再分发权利。当前`chatgpt_skill_library-0.5.0`
   wheel没有内嵌LICENSE与License元数据，须核实作者授权及所需告知文本，
   或从正式发行包移除该wheel后重验构建。SHA-256固定不构成发行授权。
2. **保留现有入口**：在不改变当前源码仓库可见性的前提下，先建立新的Public
   下载仓库，补全中英文下载/更新/安全说明和二进制使用条款。不要上传源码、
   开发密钥、真实Tunnel凭据或完整内部状态记录。
3. **迁移已发布下载资源**：至少重新发布当时仍应支持的RC.18安装包和对应校验值，
   严格比对两个位置的SHA-256；核对全新匿名浏览器可以正常访问。
4. **更新旧入口**：在现有Public仓库发布一次迁移公告及新的下载地址，
   处理README中的Git clone与`/releases`入口。GitHub外的引用可能
   永远无法全部更新，需准备迁移提示和适当过渡期。
5. **可见性转换**：上述验证后，仓库Owner在GitHub设置中主动将原开发仓库设为
   Private；此操作会改变原Releases的公开访问，并影响Stars/Watchers等。
   已存在的公开Fork不会同步变私有；历史代码可能已被他人获取。
   此步骤**不允许自动执行或假定完成**。
6. **v1.0.0候选**：冻结源码，完整回归/Windows CI/NSIS打包，最终候选源码
   commit和安装包SHA-256一一对应；至少一台非开发环境Windows机器真实验收
   首次配置、Tunnel/ChatGPT端到端、Runtime/Runner、权限开关、升级与恢复。
7. **公开正式版**：在Public下载仓库创建`v1.0.0`Tag和Release，只上传
   installer、SHA256SUMS、对外发布说明、必要合规告知文件；让匿名用户下载
   验证。私有源码仓库独立留存内部发行tag、测试记录和build记录。

## 权限与发行声明边界

- 无PLA源码开放许可，不代表限制用户依法享有的权利，或凌驾于第三方许可证。
- 需给合法获取安装包的用户明确、可阅读的软件安装和运行许可，见
  `desktop-v1-binary-terms-draft.md`。该草案未经发行负责人确认前不得
  直接作为正式许可发布。
- 当前安装包未进行代码签名、没有自动更新，且PLA不是操作系统级安全沙箱。
- 公开产品承诺限定在Desktop配置/启停、Tunnel、核心Runtime/MCP、
  Execution Runner、工作区和程序授权、诊断及基础文件/进程执行。
  Office、浏览器、Skill Library和外部组件为可选扩展，不纳入单项功能
  稳定性承诺，但不得影响核心启动与隔离边界。
