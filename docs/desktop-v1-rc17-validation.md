本地证据保存在被 Git 忽略的 `.desktop-build/rc17-*.log`、`rc17-*-report.json`、`rc17-native-candidate/`；仓库组件详细证据在日志指向的唯一临时目录。它们不是公开安装资源。首轮候选构建因验收进程占用生成资源而失败，结束本轮自有进程后重建；该失败不作为通过证据。
