# PLA Desktop v1.2.0 — Windows x64

本版集中改进多对话活动可观测性与Office组件管理。继续使用v1.1.0引入的Tauri签名更新机制；Windows安装程序本身仍未进行Authenticode发布者签名。

## 新增与改进

1. **自动对话活动统计**：在MCP工具入口读取ChatGPT提供的`_meta["openai/session"]`，对匿名标识进行哈希处理，统计最近60秒实际调用PLA的不同对话。无需模型手动登记密钥或持续心跳。不会记录原始会话标识、工具参数和聊天正文。
2. **更紧凑的活动界面**：PLA Desktop显示“活跃对话”“未识别调用”“近60秒”，桌宠同步显示摘要；详细统计口径放入提示信息。
3. **修复未知调用虚增**：桌面端内部的组件状态检查、浏览器诊断等管理MCP请求不再计为ChatGPT未知来源调用。缺少有效会话元数据的真实外部调用仍可单独统计。
4. **统一Office组件入口**：只将`office`展示为独立组件，原`wps-office`及`office-enhancement`作为其底层WPS/增强引擎保留。安装`office`时同时准备两套引擎的受审查依赖。
5. **修复原地升级残留**：遇到旧版NSIS安装资源和用户组件清单残留时，迁移程序会识别并退役未经改动、来源可确认的旧组件入口；NSIS安装后钩子清理已退役的内置JSON模板。不会删除底层执行环境、安装凭据、用户编辑过的自定义清单或授权数据。

## 安装与更新

1. 在此Release的Assets中下载`PLA.Desktop_1.2.0_x64-setup.exe`和`SHA256SUMS.txt`，核对校验和后安装。
2. 已安装v1.1.0且签名更新配置有效的用户，可以从软件中手动检查更新。升级前请保存文档并停止不希望中断的任务。没有经过真实升级验证的场景，仍可下载安装包手动升级。
3. 从v1.0.0升级的用户需要先通过安装器进入支持签名更新的版本；直接使用v1.2.0安装器也可以完成手动升级。
4. 安装器有Tauri更新签名，但没有Windows Authenticode发布者证书，因此可能出现Windows“未知发布者”提示；不要误将应用更新签名理解为操作系统层的发布者认证。

## 验证和边界

- 已进行真实ChatGPT→Tunnel→PLA的`openai/session`字段验证、同一对话多次调用指纹稳定性测试和不同对话区分测试；自动计数、SQLite持久化、60秒时窗与桌面端组件目录均已完成本地检验。
- 已验证移除旧Office入口后统一`office`仍可发现WPS、Office增强相关工具；旧执行环境和受审查依赖仍然保留。
- 自动统计是“最近60秒内实际观察到的匿名会话数”，**不是浏览器打开窗口数**。缺少元数据的客户端会归入未识别来源；长时间运行且中间无更新的调用可能暂时退出60秒时窗。
- 按源码测试结果和发布构建结果分别说明验收情况；Windows原地升级、每项Office能力以及签名篡改拒绝测试，不应在没有独立复验时声称通过。
- PLA仍按用户工作区Root、可执行程序授权、组件来源和确认策略执行，不构成操作系统安全沙箱。升级保留用户本地数据及DPAPI保护的Tunnel凭据。

正式发布使用`desktop-v1.2.0`标签与干净的已提交源码。仅允许上传构建清单标记`source_dirty=false`、`publishable=true`、`updater_signature=true`且签名/校验和匹配的安装产物。
